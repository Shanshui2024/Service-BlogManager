写作工具

使用 GitHub 登录后管理你的博客仓库。Token 安全存储在服务端会话中，登录后即可读写文章、标签与配置。

授权范围：repo。首次使用需在登录后于「仓库设置」填写 owner/repo。

标签

点击标签可查看该标签下的文章；在编辑器中也可通过中文搜索添加标签。

标签颜色

点击色块可打开系统取色器；右侧可手动输入十六进制颜色值，二者自动同步。修改后即时保存。
